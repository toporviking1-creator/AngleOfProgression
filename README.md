# Угол прогрессии (AoP) по фото УЗИ

Одностраничное веб-приложение: измеряет угол прогрессии (angle of progression) по фото экрана трансперинеального УЗИ.
Работает в браузере, офлайн после первого открытия (PWA). Фото никуда не отправляются.

**Открыть:** https://toporviking1-creator.github.io/AngleOfProgression/

## Возможности

- **Касательная по контуру черепа (авто).** 3–12 точек по наружному краю кости → по ним подбирается окружность
  (МНК), касательная из нижнего края симфиза строится автоматически. Угол ориентированный, корректен и за 180°.
  Есть контроль качества: разброс точек, слишком кучные точки, касание вне размеченного участка.
- **Касательная вручную** — классическая разметка тремя точками.
- **Выпрямление перспективы экрана.** 4 угла экрана/рамки кадра → гомография; истинное соотношение сторон
  оценивается по перспективе (Zhang & He, 2007) или выбирается вручную (16:9, 4:3 …). Разметка переносится.
- **Масштаб и точность:** щипок/Ctrl+колесо/двойной клик, панорамирование, лупа, сдвиг точки стрелками по 1 px.
- **Коррекция снимка:** яркость, контраст, авто-контраст, инверсия.
- **Интерпретация по периоду родов:** I период — порог 110° (Torkildsen 2011), II период — 120° (Kalache 2009); ISUOG 2018.
- **Журнал измерений** с динамикой (Δ° и время), копирование, хранится локально.
- **Экспорт PNG** с разметкой и подписью, «Поделиться» на телефоне.
- **Заключение** на лист А4: учреждение, пациентка, дата, снимок с разметкой, результат и способ измерения,
  динамика из журнала, редактируемый вывод, подпись. Печать или «Сохранить как PDF», копирование текста.

Ориентир для разговора с клиникой, не самостоятельное основание для клинического решения.
